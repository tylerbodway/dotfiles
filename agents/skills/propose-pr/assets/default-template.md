Ultimately, your commits should tell the story for reviewers.

### Why

- Why is this change necessary?
- Were alternative approaches considered?
- What tradeoffs were negotiated?

### Notes

- What shared context is needed to understand this change?
- Are there any next steps?
- Are there any reference links that would be helpful?

### Preview

- Are there any screenshots/recordings for visual changes?
- Are there code examples for interface changes?
- Are there diagrams that help visualize code changes?

### How to verify

- What steps can a reviewer follow to verify the change?
- Are there any edge cases or obscure flows to watch out for?
